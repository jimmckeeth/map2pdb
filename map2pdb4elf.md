# ELF Map Support for map2pdb

This document describes the implementation of support for GNU/ELF style map files in `map2pdb`, primarily to support Delphi for Linux binaries generated by `dcclinux64`.

## 1. The Issue
Prior to this update, `map2pdb` was strictly designed for the traditional Delphi (`segment:offset`) and C++ Builder map formats. When processing an ELF map file, the parser would fail with symptoms such as:

- **Fatal Parsing Errors:** `Fatal: [line] Invalid 64-bit hex number: "\program files ("`. This occurred because the parser misaligned with the ELF structure and attempted to parse file paths as hex addresses.
- **Access Violations:** Access violations in `FindByOffset` because the code assumed a valid segment was always found.
- **Overlap Errors:** Errors reporting overlapping segments like `.debug_info` and `.comment` because these non-loadable sections were being treated as standard code/data segments.

## 2. Technical Implementation

The fix involved updates across several core units to make the parsing engine more flexible and robust.

### 2.1. Indentation-Aware Parsing (`debug.info.reader.pas`)
ELF map files use indentation levels to distinguish between section headers, input sections, and symbols. The base `TLineReader` was updated to support an optional `ATrim` parameter:
- `CurrentLine(ASkipEmpty, ATrim)`
- `NextLine(ASkipEmpty, ATrim)`
- `PeekLine(ASkipEmpty, ATrim)`
By setting `ATrim := False`, the new ELF reader can reliably identify columns based on leading space counts.

### 2.2. Robust Segment Handling (`debug.info.pas`)
Added `nil` checks to `TDebugInfoModules.FindByOffset` and `TDebugInfoModules.FindOverlap`. This prevents the program from crashing if a symbol or line number points to an unmapped or ignored address space.

### 2.3. ELF Map Reader (`debug.info.reader.elfmap.pas`)
A new reader class, `TDebugInfoElfMapReader`, was implemented to handle the GNU/ELF format:
- **Section Detection:** Identifies the "Memory map" section.
- **Indentation Logic:** 
    - **0 spaces:** Loadable segments (e.g., `.text`, `.data`).
    - **1 space:** Input sections (mapping object files to segments).
    - **16+ spaces:** Symbols and cross-references.
- **Robustness:** Automatically ignores non-loadable sections (address 0) and sections starting with `.debug` or `.comment` to avoid overlap conflicts.

### 2.4. Auto-Detection (`map2pdb.dpr`)
The `TryDetectInputFormat` function was updated to automatically detect ELF maps by scanning the first 50 lines for signatures like `Discarded input sections`, `VMA`, or `LMA`.

## 3. How to Verify/Test

### 3.1. Recreating the Test Map
Use the `make-elf-map.ps1` script in the `Delphi-Disassembly` repository to generate a fresh map file using the `JustLinux` project and the `ld-linux.exe` (Gold) linker.

### 3.2. Running the Tool
Run `map2pdb` with the `-v` (verbose) flag:
```powershell
map2pdb.exe -v compilers\projects\JustLinux.map
```
**Expected Results:**
- Detection should report `ifElfMap`.
- Statistics should show modules and symbols collected (e.g., "Collected 4,206 modules, 3,529 symbols").
- A valid `.pdb` file should be generated.
